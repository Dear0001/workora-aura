# recruitment-service

Recruitment posts and candidate review workflow

## Purpose

Recruitment posts, public listings, applications, application status history,
and application-file metadata are implemented.

## Endpoints

- GET /api/health – health check
- Recruitment post create, publish, update, close, and listing endpoints
- Application create, listing, detail, status, and file-metadata endpoints

Binary file storage, interview scheduling, notifications, and advanced search
remain future work.
